# P2P-Rental

Welcome to **P2P-Rental**, a peer-to-peer rental marketplace built by Clinton Mboloi Wambua. This platform allows users to borrow and lend items directly without middlemen, making sharing easy, secure, and cost-effective.

## Features

- User registration and authentication (Google OAuth).
- Post, browse, and search listings.
- Real-time chat between lenders and borrowers.
- Secure transaction tracking and management.
- Intuitive user interface with responsive design.
- Item availability management and loan tracking.
